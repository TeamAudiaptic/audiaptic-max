# audiaptic-max
A Max/MSP integration for communcation with an Audiaptic server.

## Demo instructions
1. Run the test server in a command prompt window using npm start
2. Open the davhi_demo.maxpat patch in Max
3. Install dependencies with the install message, then run with the start message. The debug window should show the script running.
4. Send the message subpatch with the send button and view that the message was received in the test server.
